### 🚀 Featured MERN & Full-Stack Projects

#### **1. Promptify — AI Prompt Sharing & Marketplace Platform**
- **Stack:** `MongoDB` `Express.js` `Next.js 15` `Node.js` `Tailwind CSS` `Framer Motion` `BetterAuth` `Stripe`
- Built a full-stack AI prompt marketplace featuring **Role-Based Access Control (Users, Creators, Admins)** for prompt submission, moderation, and discovery.
- Integrated **Stripe Payment Gateway** for unlocking premium prompts, alongside custom bookmarking and copy-to-clipboard analytics.
- Developed analytical admin dashboards using **Recharts** and **MongoDB Aggregation Pipelines** for user reports and approval workflows.

#### **2. SportNest — Sports Facility Booking Platform**
- **Stack:** `MongoDB` `Express.js` `Next.js` `Node.js` `Tailwind CSS` `Framer Motion` `BetterAuth` `JWT`
- Engineered a full-stack turf and sports facility booking portal with dynamic time-slot management and instant reservations.
- Implemented persistent authentication using **BetterAuth & JWT** with role-protected routes and facility-owner management panels.
- Built RESTful APIs utilizing MongoDB `$regex` search, `$in` category filtering, and dynamic hourly pricing calculation.

#### **3. Multi-Vendor Grocery E-Commerce Platform**
- **Stack:** `React.js` `Zustand` `Sass` `React Router` `Vercel`
- Developed a scalable multi-vendor SaaS e-commerce frontend using **Zustand** for centralized state management.
- Designed **3 distinct role-based dashboards** (Super-Admin, Vendor, Customer) with order tracking, inventory control, and cart operations.

#### **4. Mentorship ERP — Enterprise Educational Management System** *(Company Project)*
- **Stack:** `Angular` `TypeScript` `REST API (Java Backend)` `Tailwind CSS`
- Automated student enrollment, live attendance, exam administration, and teacher workflows, **reducing manual documentation by 40%**.
